# Sufiya Hameedia Group of Institutions Website

A modern, responsive website for Sufiya Hameedia Group of Institutions - a charitable trust providing quality education across multiple programs.

**🌐 Live Website:** [https://sufiya-hameedia-trust.github.io](https://sufiya-hameedia-trust.github.io)

## About

Sufiya Hameedia Trust operates three educational institutions:
- **Higher Primary School** - English Medium Day School (LKG to Grade 5)
- **Arabic Madrasa** - Islamic education with modern approach
- **Night Coaching Classes** - Evening education (9:00 PM - 11:00 PM)

## Key Features

- 📱 Mobile-responsive design
- 📸 Photo gallery with real school photos
- 💰 UPI donation system
- 📢 Announcements and feedback system
- 🌍 Multilingual support (English/Urdu)
- 🗺️ Interactive location map

## Quick Updates

1. **Make changes** locally
2. **Copy to GitHub** via web interface
3. **Deploy**: Settings → Pages → Select branch
