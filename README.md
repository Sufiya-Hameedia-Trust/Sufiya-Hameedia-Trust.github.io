# Sufiya Hameedia Group of Institutions Website

A modern, responsive website for Sufiya Hameedia Group of Institutions - a charitable trust providing quality education across multiple programs including Higher Primary School, Arabic Madrasa, and Night Coaching Classes.

## About Sufiya Hameedia

Sufiya Hameedia is committed to providing quality education and fostering individual creativity, social skills, and academic excellence for all age groups. The trust operates three main educational institutions:

- **Higher Primary School** - Complete English Medium Day School (LKG to Grade 5)
- **Arabic Madrasa** - Islamic education with modern approach
- **Night Coaching Classes** - Continuing education for working professionals

## Website Features

- 📱 **Mobile-First Responsive Design** - Optimized for all devices
- 🎨 **Modern UI/UX** - Clean, professional design with smooth animations
- 🏫 **Institution Pages** - Dedicated pages for each educational program
- 📞 **Direct Contact Links** - Click-to-call phone numbers
- 🗺️ **Interactive Map** - Embedded Google Maps for location
- 💰 **Donation System** - QR code integration for easy donations
- ♿ **Accessibility** - Semantic HTML and ARIA labels

## Technology Stack

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with CSS Grid and Flexbox
- **JavaScript** - Interactive functionality
- **Google Fonts** - Inter and Playfair Display typography
- **Google Maps** - Location integration

## Local Development

1. Clone this repository
2. Open `index.html` in your web browser
3. For development, use a local server (e.g., Live Server extension in VS Code)

## Deployment

This website is deployed using GitHub Pages and can be accessed at the institution's domain.
